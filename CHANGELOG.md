# Changelog

## 1.1.0
- Паразитное питание (два провода): `begin()` сам узнаёт питание датчиков командой Read Power Supply и на время измерения держит линию на питании; линия отпускается перед любым обменом и по `ready()`.
- `setPowerMode(POWER_AUTO / POWER_EXTERNAL / POWER_PARASITE)`, `isParasite()`, `setPowerPin(пин, activeHigh)` для внешнего ключа питания на полевом транзисторе (много датчиков, длинные провода).
- `diagnose()` показывает тип питания и подсказку при 85 °C в паразитном режиме. Пример `ParasitePower`.
- Тесты: имитация линии теряет измерение, если питание не подано сразу, пропало раньше времени или обмен идёт при включённом питании; мутации ловятся.

## 1.0.1
- Примеры: описание в начале каждого примера на русском, казахском и английском.

## 1.0.0
- Первый выпуск: DS18B20, DS18S20, DS1822 на линии 1-Wire без зависимостей (свой слой 1-Wire: сброс, биты, поиск устройств, CRC8).
- Поиск всех датчиков на линии, несколько датчиков на одном проводе, измерение всех сразу.
- Измерение без блокировки (`request()` / `ready()`), точность 9-12 бит.
- Понятные ошибки и `diagnose()` на русском, казахском и английском.
